# v4 content-model additions

## Student Work

Added:

- age at completion
- grade at completion
- dimensions
- instructor references
- artist statement
- optional student/process photo + separate publish permission
- approved public student portrait from the linked Student record
- richer award details and certificate/award imagery
- age-group gallery filtering
- richer artwork detail dialog

Animation work uses the same Student Work and Award model as Studio Art. The thumbnail continues to link directly to the hosted video; a separate “View details” control opens the same rich metadata/award view used by Studio Art.

## Parent-facing information

Programs can now hold optional structured age range, schedule summary, enrollment status, and registration notes. These are more useful to parents than adding generic promotional paragraphs.

Optional FAQs can appear below tuition. Optional testimonials can appear on the homepage only after publication permission is confirmed. No FAQ answers or testimonials are seeded automatically.
